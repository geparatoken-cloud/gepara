# GEPARA

**Dosya Kanıtı / File Proof** — prove a file existed on a given date. Free, no account. The file never leaves your device; only its SHA-256 fingerprint is sent to public OpenTimestamps calendars and anchored in the Bitcoin blockchain.

- `dosya-kaniti.html` — get a proof (.ots), create a handover photo pack, check a file
- `index.html` — GEPARA expert report verification (Polygon)
